Context

Why build another notes app?

✕ The Problem

Most note-taking apps feel either overly complex (Notion's learning curve) or visually stark (Obsidian's markdown-first approach). I wanted something that felt intentional and beautiful by default—an app where the design itself encouraged focus and clear thinking.

✓ The Approach

Northfork Notes prioritizes aesthetics and simplicity. Serif typography sets the tone. A clean, minimal interface removes distractions. Block-based editing provides flexibility without overwhelming options. Every design decision asks: "Does this help or hinder the writing experience?"

Learnings

What I've learned building this

The notes app market is saturated—distribution matters

Building a great product isn't enough. In a crowded space, tight niche positioning and strong distribution channels (Product Hunt, Indie Hackers) are essential for differentiation.

Mobile responsiveness requires dedicated effort

"It works on mobile" isn't the same as "it's good on mobile." Touch targets, sidebar behavior, and viewport handling all needed dedicated attention.

Optimistic UI transforms user experience

Drag-and-drop felt sluggish until I implemented optimistic updates with database sync and rollback. The perceived performance improvement was dramatic.

Security practices need to be habits, not afterthoughts

Keeping secrets out of version control (proper .env.local usage, Vercel dashboard for deployment vars) needs to be automatic. Row Level Security in Supabase adds another essential layer.
